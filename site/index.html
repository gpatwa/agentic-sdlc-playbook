Common questions

Straight answers.

Is this a coding agent?

No. It directs the agent you already use; today that is Claude Code.

Do I approve every step?

No. One Charter at the start, by its hash. The run stops only for something the Charter does not name, spend past its cap, or a credential.

Why a subscription instead of an API key?

It runs on the plan you already pay for, so there is no separate API bill; your plan’s usage window is the limit.

How is it different from other tools?

Many have a plan step and an audit log. Aveto’s difference is what is approved and by whom: one hashed Charter, by a person.

Does it work for a team?

Each developer on their own subscription works now. Shared team gates are on the roadmap, not shipped.
